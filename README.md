# MyKnowledge

个人 Obsidian 知识库：课程笔记 + 概念卡片 + 原始素材。

## 目录结构

- `Knowledge/Concepts/<分类>/` — 概念笔记，统一使用 `type: concept` 模板并带 `domain` 字段；每个分类一个 `_索引_<分类>.md`（如 `_索引_历史.md`），总览见 `Knowledge/Concepts/索引.md`
- `Knowledge/Notes/` — 课程/阅读笔记（Game Theory 系列等），索引见 `Knowledge/Notes/_索引_笔记.md`
- `Raw Materials/` — 原始素材，只读、禁止改动，不纳入 git 跟踪
