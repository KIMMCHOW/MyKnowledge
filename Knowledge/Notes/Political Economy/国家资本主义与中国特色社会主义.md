# 国家资本主义与中国特色社会主义

> [!summary] 摘要
> “国家资本主义”没有统一跨理论定义，常用来描述国家作为资本所有者、控制者、融资配置者或产业政策制定者参与市场竞争。判断中国是否适用，必须区分国家所有权、国家控制与中央计划，并做经验检验。

## 国家资本主义 / State Capitalism

“国家资本主义”没有跨理论传统完全统一的定义。常见用法是国家作为重要资本所有者、控制者、融资配置者或产业政策制定者参与市场竞争与资本积累，经济仍包含工资劳动、利润激励和价格信号。**国家所有权 ≠ 国家控制 ≠ 中央计划**，三者必须区分。

## 为什么中国会被如此描述？

中国同时具有国有企业、政策性金融、战略行业国家控制，与民营企业、市场竞争及资本积累。一些比较政治经济学研究据此强调国家与市场的深度结合，将部分机制或整体制度称作 state capitalism。

## 反对这一分类的论据

中国官方将制度表述为社会主义初级阶段的社会主义市场经济，强调公有制主体地位、多种所有制经济共同发展、共同富裕等目标；部分学者认为“国家资本主义”不足以涵盖政治目标、产权结构及不同历史阶段的差异。

## 判断框架 / Evaluation

比较资产、就业、投资控制、信贷配置、剩余分配、劳动关系、公司治理及行业差异。不应因为存在国企就断言整个制度必然为国家资本主义，也不应因为自称社会主义就跳过经验检验。概念是分析透镜，不是无需论证的结论。
