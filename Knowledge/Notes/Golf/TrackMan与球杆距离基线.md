# TrackMan与球杆距离基线

## 指标 / Metrics
Club Speed（杆速）、Ball Speed（球速）、Smash Factor（效率）、Attack Angle（攻角）、Dynamic Loft（动态杆面角）、Launch Angle（起飞角）、Spin、Carry/Total（空中/总距离）必须分开。球路初始方向主要受杆面影响，曲率由 face-to-path 关系显著影响。

## 个人基线 / Personal Baseline (2026-10-15)
| Club | Carry (yd) |
|---|---:|
| Driver | 260 |
| 7i | 160 |
| 8i | 145 |
| 9i | 130 |
| PW | 115 |
| 54° | 85 |
| 58° | 70 |

记录属于个人训练参考，不能当作所有击球的期望距离。TrackMan 自动排除严重失误球时，均值可能偏高。每支杆建议记录未筛选球数、median carry、标准差、左右散布和失误率。

Driver→7i 与 PW→54° 的距离空档应优先实测，再决定增加球道木、混合杆或 50° 挖起杆。
