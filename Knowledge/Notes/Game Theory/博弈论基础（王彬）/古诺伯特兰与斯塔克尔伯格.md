# 古诺伯特兰与斯塔克尔伯格

**Cournot / 古诺数量竞争** 企业同时选产量 q_i。设 P=a−b(q_1+q_2)，常数边际成本 c，利润 π_i=(P−c)q_i。当 a>c 时，两家对称厂商的反应函数 q_i=(a−c−b q_j)/(2b)，均衡产量各为 (a−c)/(3b)。

**Bertrand / 伯特兰价格竞争** 在同质品、相同恒定边际成本、无容量约束、消费者选最低价等严格假设下，两家定价的均衡为 p=c。产品差异、产能约束会改变结论。

**Stackelberg / 斯塔克尔伯格先后产量竞争** 在同一线性需求与成本设定下，先行者考虑跟随者的最优反应 q_2=(a−c−b q_1)/(2b)，由后向归纳得到 q_1=(a−c)/(2b)，q_2=(a−c)/(4b)。

对比说明：战略变量（价格/数量）及行动顺序都能系统性地改变均衡。
