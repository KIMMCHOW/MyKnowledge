# 静态博弈求解与经典案例

首先定义参与者 N、策略集 S_i 和收益函数 u_i。纯策略纳什均衡 s* 满足任意 i 与替代策略 s_i，u_i(s*)≥u_i(s_i,s*_-i)。严格占优策略的收益优于所有其他策略，不依赖对手选择；严格劣势策略的迭代剔除可能缩小求解空间。弱劣势策略的迭代剔除则可能依赖剔除顺序。

**例：囚徒困境** 双方选择合作 C 或背叛 D；当 T>R>P>S 时，D 严格占优而 (D,D) 为纳什均衡，但 (C,C) 帕累托优于 (D,D)。这表明均衡稳定不等于有效率。

**案例辨析** 鹰鸽博弈的战略替代性可能产生不对称纯均衡；协调博弈可能有多个均衡，需要解释焦点、历史预期；银行挤兑可由信念形成自我实现；公地悲剧是私人边际收益与社会边际成本不一致。以上例子机制不同，不应统称囚徒困境。
