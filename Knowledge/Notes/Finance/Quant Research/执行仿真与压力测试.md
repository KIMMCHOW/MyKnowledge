# 执行仿真与压力测试

**事件链 / Event Chain.** Signal → order submit → accepted/rejected → partial/full fill → cancel/replace → closed/reconciled。策略与执行器必须区分订单已发送、broker 已确认与仓位真实变化。

**回测真实性 / Simulation.** Bid/ask、slippage、market impact、latency、exchange calendar、session flatten buffer、stop触发后的订单类型影响成交。分钟 OHLC 同时触及止损与目标时，不能假装知道事件先后；应采用逐 tick 回放或有偏误说明的保守假设。

**测试 / Stress.** 扩点差、掉线、部分成交、拒单、持仓不匹配、订单重复回报、DST、提前收市、换月跨期。提供每种情景下账户最大损失和错误恢复动作。
