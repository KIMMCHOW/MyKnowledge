# 翻译说明与术语表

## 排版约定

- 英文原文放在 `English` callout 中，中文紧随其后。
- 章节名采用“中文 / English”的形式。
- 首次出现的重要概念保留英文，如“隐含波动率（implied volatility）”。
- Delta、Gamma、Theta、Vega、Rho 等交易界通用写法不强制译成中文。
- 公式、变量、执行价和例题数字保持原样。
- `underlying` 根据语境译为“标的”或“标的合约”，避免直译为不准确的中文。
- `position` 译为“头寸”；强调多腿整体时可译为“组合头寸”。
- `spread` 指交易结构时译为“价差策略”，指买卖报价差时译为“买卖价差”。

## 容易混淆的表达

### Price 与 Value

- `price` 是市场给出的价格。
- `value` 是交易者或模型估计的价值。
- 两者不同才可能产生 `theoretical edge`。

### Realized Volatility 与 Implied Volatility

- `realized volatility` 描述标的实际发生的价格运动。
- `implied volatility` 描述市场通过期权价格表达的波动率水平。
- Gamma 更接近实际运动风险；Vega 更接近隐含波动率变化风险。

### Margin 与 Variation

- `margin` 是为保证履约而存入的保证金，理论上仍属于交易者。
- `variation` 是期货逐日盯市产生的实际现金流，方向直接标记为 `variation credit` 或 `variation debit`。
