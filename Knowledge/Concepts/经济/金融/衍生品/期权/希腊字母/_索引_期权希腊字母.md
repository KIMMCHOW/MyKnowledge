# 期权希腊字母

> [!definition] Greeks
> Greeks 是期权理论价值对定价变量的局部敏感度坐标。它们描述当前位置附近的风险，不等同于完整的情景损益，也不能替代全重估。

## 统一符号

令期权理论价值为

$$
V=V\!\left(S,\sigma,t,r_d,r_f,q\right)
\qquad\text{且}\qquad
\tau=T-t
$$

| 符号 | 含义 |
| --- | --- |
| $V$ | 期权理论价值；看涨期权可写作 $C$，看跌期权可写作 $P$ |
| $S$ | 标的价格或即期价格 |
| $\sigma$ | 年化波动率 |
| $t$ | 当前时间 |
| $\tau=T-t$ | 剩余期限 |
| $r_d$ | 本国利率或主要定价利率 |
| $r_f$ | 外国利率 |
| $q$ | 股票的连续股息率；其敏感度写作 $\partial V/\partial q$，不称为 Phi |

> [!important] 时间导数的符号
> 本目录中 Theta、Charm、Color 和 Vega decay 均按当前时间 $t$ 向前推进来定义。由于 $\tau=T-t$，因此
> $$
> \frac{\partial}{\partial t}=-\frac{\partial}{\partial\tau}.
> $$
> 如果某条公式直接对剩余期限 $\tau$ 求导，应直接写偏导数并记住与命名时间 Greeks 符号相反，不再另造下标名称。

## 一阶敏感度

| 指标 | 数学定义 | 主要风险 |
| --- | --- | --- |
| [[Delta]] | $\displaystyle \Delta=\frac{\partial V}{\partial S}$ | 标的方向变化 |
| [[Lambda（期权杠杆率）\|Lambda]] | $\displaystyle \Lambda=\frac{S}{V}\frac{\partial V}{\partial S}$ | 期权价值对标的价格的百分比杠杆（弹性） |
| [[Theta]] | $\displaystyle \Theta=\frac{\partial V}{\partial t}=-\frac{\partial V}{\partial\tau}$ | 时间流逝 |
| [[Vega]] | $\displaystyle \mathrm{Vega}=\frac{\partial V}{\partial\sigma}$ | 波动率变化 |
| [[Rho]] | $\displaystyle \rho_d=\frac{\partial V}{\partial r_d}$ | 本国利率或主要利率变化 |
| [[Phi\|Rho-f / Phi]] | $\displaystyle \Phi=\frac{\partial V}{\partial r_f}$ | 外国利率变化 |

> [!note] 股息率敏感度
> 股票期权对连续股息率 $q$ 的敏感度直接写作 $\partial V/\partial q$。Phi 在本目录中只指外币利率 $r_f$ 敏感度，不作为股息率敏感度的名称。

## 二阶敏感度

| 指标 | 数学定义 | 主要风险 |
| --- | --- | --- |
| [[Gamma]] | $\displaystyle \Gamma=\frac{\partial^2V}{\partial S^2}$ | Delta 的价格漂移与凸性 |
| [[Vanna]] | $\displaystyle \mathrm{Vanna}=\frac{\partial^2V}{\partial S\,\partial\sigma}$ | Delta 与 Vega 的交叉变化 |
| [[Charm]] | $\displaystyle \mathrm{Charm}=\frac{\partial^2V}{\partial S\,\partial t}=-\frac{\partial\Delta}{\partial\tau}$ | Delta 随时间流逝的变化 |
| [[Volga（Vomma）\|Volga / Vomma]] | $\displaystyle \mathrm{Volga}=\frac{\partial^2V}{\partial\sigma^2}$ | Vega 随波动率变化 |
| [[Vega Decay\|Vega decay]] | $\displaystyle \mathrm{VegaDecay}=\frac{\partial^2V}{\partial\sigma\,\partial t}=-\frac{\partial\mathrm{Vega}}{\partial\tau}$ | Vega 随时间流逝的变化 |

## 三阶敏感度

| 指标 | 数学定义 | 主要风险 |
| --- | --- | --- |
| [[Speed]] | $\displaystyle \mathrm{Speed}=\frac{\partial^3V}{\partial S^3}$ | Gamma 随标的价格变化 |
| [[Color]] | $\displaystyle \mathrm{Color}=\frac{\partial^3V}{\partial S^2\,\partial t}=-\frac{\partial\Gamma}{\partial\tau}$ | Gamma 随时间流逝的变化 |
| [[Zomma]] | $\displaystyle \mathrm{Zomma}=\frac{\partial^3V}{\partial S^2\,\partial\sigma}$ | Gamma 随波动率变化 |

## 局部价值展开

为把本目录收录的一、二阶 Greeks 放在同一个风险近似中，下面仅保留这些已列指标对应的项：

$$
\begin{aligned}
dV\approx{}&
\Delta\,dS
+\Theta\,dt
+\mathrm{Vega}\,d\sigma
+\rho_d\,dr_d
+\Phi\,dr_f
+\frac{\partial V}{\partial q}\,dq \\
&+\frac{1}{2}\Gamma(dS)^2
+\mathrm{Vanna}\,dS\,d\sigma
+\mathrm{Charm}\,dS\,dt \\
&+\frac{1}{2}\mathrm{Volga}(d\sigma)^2
+\mathrm{VegaDecay}\,d\sigma\,dt.
\end{aligned}
$$

这是一条**截断近似**，不是完整的二阶多元 Taylor 展开；它省略了本目录未单列的时间凸性项
$\tfrac12(\partial^2V/\partial t^2)(dt)^2$，以及含利率的二阶项和其他交叉项。

与 Gamma 直接相关的主要三阶项为

$$
\frac{1}{6}\mathrm{Speed}(dS)^3
+\frac{1}{2}\mathrm{Color}(dS)^2dt
+\frac{1}{2}\mathrm{Zomma}(dS)^2d\sigma.
$$

Lambda 不单独出现在价值的 Taylor 展开中；它是 Delta 的百分比标准化形式：

$$
\frac{dV}{V}\approx\Lambda\frac{dS}{S}.
$$

## 共同使用原则

- 统一合约乘数、币种、时间、价格、波动率和利率单位。
- 一阶指标适合很小的单变量变化；二阶和三阶指标用于描述敏感度本身如何漂移。
- 大幅行情、跳空、临近到期或多变量同时变化时，应进行全重估与压力测试。
- 单项中性不代表组合无风险，还需观察波动率曲面、期限结构、流动性和尾部风险。
