# 风险调整绩效指标

任何单一指标都压缩了收益路径的信息。评价策略时应同时观察中心趋势、波动、下行风险、回撤和尾部分布。

| 指标 | 主要回答的问题 | 主要局限 |
| --- | --- | --- |
| [[夏普比率]] | 每单位总波动获得多少超额收益？ | 上下行波动同等计入，受非正态和自相关影响 |
| [[索提诺比率]] | 每单位下行偏差获得多少超额收益？ | 依赖目标收益率与下行样本数量 |
| [[卡玛比率]] | 年化收益能否补偿最大回撤？ | 只使用单次最深回撤，路径依赖强 |
| [[条件风险价值]] | 最差尾部情景平均损失多少？ | 依赖置信水平、估计方法与样本 |
| [[峰度]] | 极端观测倾向有多强？ | 不区分方向，不能完整描述尾部 |
| [[偏度]] | 收益分布的尾部方向如何？ | 对离群值敏感，不表示损失规模 |

## 使用顺序

1. 统一收益频率、费用、基准和年化口径。
2. 同时查看累计净值、回撤曲线和收益分布。
3. 用多个指标交叉验证，不按单一最高数值选择策略。
